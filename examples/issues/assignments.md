# Assignments

Active work ownership ledger.

Each active assignment must be tracked as a single line:

`- task_id: <id> | owner: <agent> | worktree: <absolute-path> | branch: <branch-name> | lease_until: <YYYY-MM-DDTHH:MM:SSZ>`

Example:

`task_id: e2e-webhook-synchronization | owner: copilot | worktree: /home/yago/worktrees/e2e-webhook-synchronization | branch: task/e2e-webhook-synchronization | lease_until: 2026-04-20T21:00:00Z`
