## Context

Mobile users struggle with the file upload step during checkout — it's unclear what file types and sizes are accepted, and errors appear too late.

## Objective

Add inline guidance and early client-side validation to the file upload component.

## Acceptance Criteria

- [ ] Accepted formats and max size displayed before interaction.
- [ ] Client-side validation fires before upload starts.
- [ ] Error messages are actionable and specific.
